🎯 CrateMatch Mac app

Your own version of djay's Match feature — for the Serato offline library. Pick a track, get ranked similar songs by BPM, key and energy, preview them, and export the picks as a Serato crate.

What it does

  • Scans your music folder and analyzes every track: BPM, musical key (Camelot code), energy, and spectral character
  • Results cached in SQLite — first scan takes a while, every scan after is fast
  • Pick any song → ranked list of similar tracks from your own library
  • One-tap preview, then export your picks as a real Serato .crate

Setup

  • MacBook with Python 3
  • pip install librosa mutagen plus ffmpeg
  • Point it at your music folder and let the first scan run
